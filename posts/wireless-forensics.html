Clearing the Air: Wireless Forensics

Week 7 Session

Wireless forensics brings unique challenges like signal range and encryption. We learned to use "Monitor Mode" to capture 802.11 management frames, which helps in identifying rogue Access Points and deauthentication attacks.

Key Concepts

Frames: Analyzes Management (Beacon), Control (ACK), and Data frames.

Tools: Uses monitor mode and tools like Wireshark and Kismet to capture 802.11 traffic.

Unique Challenges of Wireless Forensics

Wireless network forensics presents challenges not found in wired networks:

  • Signal Range: Wireless signals extend beyond physical boundaries
  • Encryption: WPA2/WPA3 encryption makes data capture more complex
  • Mobility: Devices can move and connect to different access points
  • Interference: Radio frequency interference can affect captures
  • Passive Monitoring: Requires special capture modes

802.11 Frame Types

Management Frames

Management frames control network access and include:

  • Beacon Frames: Broadcast by access points to announce network presence
  • Probe Requests/Responses: Used by clients to discover networks
  • Association/Reassociation: Client connection to access points
  • Deauthentication: Can be used in attacks to disconnect clients

These frames are unencrypted and provide valuable forensic information even when data is encrypted.

Control Frames

Control frames manage frame delivery:

  • ACK (Acknowledgment): Confirms frame receipt
  • RTS/CTS: Request to Send/Clear to Send for collision avoidance

Data Frames

Data frames carry the actual network traffic. When encrypted, they require the encryption key for analysis.

Monitor Mode

Monitor mode (also called RFMON mode) is essential for wireless forensics because it allows:

  • Passive capture of all 802.11 traffic on a channel
  • Capture without being associated with an access point
  • Capture of management and control frames
  • Detection of hidden networks

Unlike promiscuous mode on wired networks, monitor mode is required for wireless because the adapter must operate at the radio frequency level.

Forensic Applications

Rogue Access Point Detection

By analyzing beacon frames, investigators can identify:

  • Unauthorized access points
  • Evil twin attacks (fake access points)
  • Access points with suspicious configurations

Deauthentication Attack Detection

Deauthentication attacks can be detected by analyzing:

  • Unusual patterns of deauthentication frames
  • Frames sent to broadcast addresses
  • Rapid disconnection/reconnection patterns

Tools for Wireless Forensics

Wireshark

Wireshark can capture and analyze 802.11 frames when used with a wireless adapter in monitor mode. It provides detailed frame analysis and filtering capabilities.

Kismet

Kismet is a wireless network detector, sniffer, and intrusion detection system. It's particularly useful for:

  • Passive network discovery
  • Detecting hidden networks
  • Identifying network clients
  • Logging all detected networks

Best Practices

  • Use monitor mode for passive captures
  • Capture on multiple channels if possible
  • Document signal strength and location
  • Preserve encryption keys if available
  • Correlate wireless captures with wired network evidence
