Following the Intruder's Footprints

Week 8 Session

In forensics, we track actions, not names. By using IDS logs, we can identify unusual port usage or protocol misuse like DNS tunneling. Remember: blocking an attack with IPS is good for security, but it often makes the forensic evidence weaker.

Key Concepts

Focus: Tracking is about understanding attacker behavior (entry points, movement, footprints) rather than their physical identity.

IDS vs. IPS: IDS provides higher forensic value because it passively logs data, whereas IPS focus is on blocking.

Understanding Intruder Tracking

Network forensics focuses on tracking attacker actions and behavior patterns rather than identifying the physical person. We track:

  • Entry Points: How the attacker gained initial access
  • Movement: Lateral movement through the network
  • Footprints: Evidence of attacker activities and modifications

Using IDS Logs

Intrusion Detection Systems (IDS) are invaluable for tracking intruders because they:

  • Passively monitor network traffic
  • Generate detailed logs of suspicious activity
  • Don't interfere with traffic (preserving evidence)
  • Can detect patterns that might be missed in manual analysis

Identifying Suspicious Patterns

Unusual Port Usage

Attackers often use non-standard ports to evade detection. IDS logs can reveal:

  • Services running on unexpected ports
  • Port scanning activities
  • Backdoors on unusual ports

Protocol Misuse

Attackers frequently misuse legitimate protocols for malicious purposes:

  • DNS Tunneling: Using DNS queries to exfiltrate data or establish C2 channels
  • HTTP Tunneling: Encapsulating other protocols within HTTP
  • ICMP Tunneling: Using ICMP packets for data transfer

IDS vs. IPS: Forensic Implications

IDS (Intrusion Detection System)

IDS systems are passive—they monitor and log but don't block traffic. This makes them ideal for forensics because:

  • They preserve complete evidence
  • They don't alert attackers that they've been detected
  • They provide comprehensive logs for analysis

IPS (Intrusion Prevention System)

IPS systems actively block attacks, which is good for security but can weaken forensic evidence because:

  • Blocked traffic may not be fully logged
  • Attackers may change tactics when blocked
  • Some evidence may be lost when connections are terminated

Best Practices

For maximum forensic value:

  • Use IDS for monitoring and logging
  • Maintain comprehensive logs of all alerts
  • Correlate IDS alerts with other evidence sources
  • Document all findings in a timeline
