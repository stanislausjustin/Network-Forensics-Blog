My final project is Forensic Analysis of Unauthorized Configuration File Access: Investigating F5 BIG-IP Exploitation via Network Traffic Capture.

Project Overview

The project involved analyzing a packet capture file from a honeypot environment to investigate exploitation attempts against F5 BIG-IP Management Interface (CVE-2020-5902). The analysis focused on detecting malicious activity, determining root causes, and reconstructing the attack workflow.
