Decoding the Protocol Trail

Week 3 Session

Every network communication leaves a fingerprint. We looked at how transport layers (TCP/UDP) and application layers (DNS, HTTP) provide clues. For example, abnormal TCP flags can indicate an attacker trying to cover their tracks.

Key Concepts

Protocol Value: Different protocols leave unique fingerprints (e.g., TCP flags for session reconstruction, DNS for finding C2 domains).

Understanding Protocol Fingerprints

Network protocols operate at different layers of the OSI model, and each layer provides different types of forensic evidence. Understanding these layers and their protocols is crucial for effective network forensics.

Transport Layer Protocols

TCP (Transmission Control Protocol)

TCP provides connection-oriented communication with flags that indicate connection state. Abnormal TCP flags can reveal:

  • Port scanning attempts (SYN flags without ACK)
  • Connection hijacking attempts
  • Attempts to evade detection

TCP flags are essential for session reconstruction, allowing investigators to piece together fragmented communications.

UDP (User Datagram Protocol)

UDP is connectionless and provides less information than TCP, but it's commonly used for DNS queries, which can reveal command and control (C2) domains used by attackers.

Application Layer Protocols

DNS (Domain Name System)

DNS queries can reveal malicious domains used for command and control. Unusual DNS patterns, such as:

  • Frequent queries to unknown domains
  • DNS tunneling attempts
  • Queries to domains associated with known malware

These patterns are critical indicators of compromise.

HTTP/HTTPS

HTTP headers and request patterns can reveal:

  • User agents used by attackers
  • Data exfiltration patterns
  • Malicious payload delivery

Forensic Value

Each protocol provides unique forensic value. TCP flags help reconstruct sessions, DNS queries reveal C2 infrastructure, and application layer protocols show what attackers were actually doing. Understanding these protocol fingerprints is essential for effective network forensics.
