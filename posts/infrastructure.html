Infrastructure Devices

Week 10 Session

Infrastructure devices like switches and routers are gold mines for evidence. We focused on CAM and ARP tables to map physical locations to IP addresses. Always remember to check if the router itself has been compromised!

Key Concepts

Switches/Routers: Sources of volatile evidence like CAM tables (MAC-to-port mappings) and ARP tables (MAC-to-IP mappings).

Infrastructure Devices as Evidence Sources

Network infrastructure devices—switches, routers, and firewalls—contain valuable forensic evidence that is often overlooked. These devices maintain tables and logs that can provide crucial information about network activity.

Switch Evidence

CAM (Content Addressable Memory) Tables

Switches maintain CAM tables that map MAC addresses to physical switch ports. This information is critical because it allows investigators to:

  • Identify which physical port a device was connected to
  • Track device movement within the network
  • Correlate MAC addresses with network activity
  • Identify unauthorized devices on the network

Important: CAM tables are volatile and can be cleared or age out, so they must be captured quickly.

Router Evidence

ARP (Address Resolution Protocol) Tables

Routers maintain ARP tables that map MAC addresses to IP addresses. This provides:

  • IP-to-MAC address mappings
  • Information about devices that have communicated recently
  • Evidence of IP address spoofing attempts

Routing Tables

Routing tables show how traffic is routed through the network, which can reveal:

  • Network topology at the time of investigation
  • Routing changes that might indicate compromise
  • Path of data exfiltration

Critical Security Consideration

Always check if the router itself has been compromised! If an attacker has gained administrative access to a router, they can:

  • Modify routing tables
  • Redirect traffic
  • Modify or delete logs
  • Install backdoors

Before trusting router evidence, verify the integrity of the router's configuration and logs.

Firewall Logs

Firewalls generate extensive logs that can show:

  • Blocked connection attempts
  • Allowed connections
  • Port scans and attack patterns
  • Data exfiltration attempts

Best Practices

  • Capture volatile tables (CAM, ARP) immediately
  • Document the physical location of devices
  • Verify device integrity before trusting evidence
  • Maintain regular backups of device configurations
  • Correlate infrastructure evidence with other sources
